# Visual Reference Notes

This folder is for palette studies, screenshots, paintings, and other inspiration for `meadow`.

Raw third-party references stay local and are ignored by Git. Commit only project-authored
concept studies and palette boards derived from them.

## Working preferences

- Final mockups and concept studies should be delivered as `PNG` or `JPG` by default.
- Do not hand off `SVG` as the primary review format unless explicitly requested.
- The palette references in this folder are approved inputs for future mockups.
- Future visual passes should prefer a true continuous hex grid with smaller cells over detached tile shapes.
